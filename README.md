# Headline

A multiplayer first-person shooter that runs in the browser. Built with React, Three.js and Node.

## Run

```bash
npm install
npm run dev
```

Then open `http://localhost:5173`. Open it in two tabs to play against yourself.

## Production

```bash
npm run build
npm start
```

The game is served at `http://localhost:3001`. Set `PORT` to change the port.

## Test

```bash
npm run test:smoke
```
